# db-design
# 实验二：数据库设计
## 实验目标
掌握ER图设计、范式化理论、建表语句编写和外键约束。
## 实验要求
1. 为「在线商城」系统设计ER图（用户/商品/订单/购物车等实体）
2. 将ER图转化为关系模式，确保达到3NF
3. 编写完整建表SQL（含主键、外键、CHECK约束）
4. 设计合理的数据类型和字段长度
5. 编写索引设计说明（哪些字段需要索引及原因）
## 评分标准
| 项目 | 分值 |
|------|------|
| ER图设计 | 25% |
| 范式化 | 25% |
| 建表SQL | 25% |
| 索引设计 | 15% |
| 文档规范 | 10% |
